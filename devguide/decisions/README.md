# Decisions

A decision that shapes a public contract, with the evidence that decided it and
what was rejected along the way.

These are not archived proposals. A proposal describes a problem and asks a
question; a decision here answers it, and says what would reopen it. When one is
revisited, the new reasoning is added to the same file rather than replacing it,
so the record shows how the answer moved.

A document lives in `../pending_proposals/` while its question is open, and moves
here when it is answered.
